W Hunt Randomizer

2026

A Hunt: Showdown random loadout generator.

The main purpose of this project was to help me learn Godot and to test the engine’s viability for building Desktop and Web applications.

The app was built by getting the game’s weapon and equipment images from its wiki using Python, and then converting them to data that can be read by the engine. Every potential loadout element has not only an image, but also an entire JSON file with its stats and ammo types that can later be used to do more interesting things with the loadouts and to style the app better. Written mostly in GDScript.

Visuals are mostly built-in Godot nodes, but there are also a couple custom shaders:

  • Outline/shadow
  • Fake perspective
