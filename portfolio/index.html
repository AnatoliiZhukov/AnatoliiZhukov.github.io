W Hunt Randomizer
2026
A random loadout generator.
The main purpose of this project was to help me learn Godot and to test the engine’s viability for building Desktop and Web applications.


Weapon and equipment data along with images were taken from the game’s wiki using a Python web scraper, a custom editor tool was then used to create Resource files. Every piece of equipment has an image, a Resource file, and a JSON file with its stats, with all of it being easily accessible.


Written mostly in GDScript, it was the only suitable option for a Web app.


Visuals are mostly built-in Godot nodes, but there are also a couple custom shaders:


    

  • Outline/shadow
    • 

  • Fake perspective
    • 



*All game-related assets are property of Crytek, this fan-made tool is not affiliated or endorsed by them.
